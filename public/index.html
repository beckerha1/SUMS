SUMS — Free Daily Number Puzzle Game

SUMS is a free daily number logic puzzle at sums.games. Fill a grid by placing numbers in order (1, 2, 3, and so on). To place the next number, select two or more adjacent cells that add up to it, then tap an empty cell touching your selection.

Play Mini SUMS (5×5) for a short solve or Full SUMS (7×7) for a longer challenge. New puzzles every day.

How to play

  1. Look at the gray clue numbers already on the board.
  2. Place numbers in sequence, starting from 1.
  3. Select a connected chain of cells whose values add up to your next number.
  4. Place that number in an empty cell that touches the start or end of the chain.
  5. Fill every empty cell to win. Undo is available if a placement blocks the path.

Game modes

  • Mini SUMS: 5×5 grid, usually a few minutes.
  • Full SUMS: 7×7 grid with more planning, clues, and walls.
  • Hard mode: limits how many cells you can select at once.

SUMS is created by Xavier Games and is free to play in any modern browser.
